# 🌍 Travel Website

A simple travel website created using **only HTML and CSS**.  
It includes separate pages for **Hotels, Restaurants, and Flights**, connected using HTML anchor tags.

## ✨ Features

- 🏨 Hotels page  
- 🍽️ Restaurants page  
- ✈️ Flights page  
- 🔗 Navigation using anchor tags  
- 🎨 Simple and clean design  
- 📱 Responsive layout using CSS  

## 🛠️ Technologies Used

- HTML5  
- CSS3  

## 📄 Pages

| Page | Description |
|---|---|
| Home | Main page of the travel website |
| Hotels | Displays hotel details and options |
| Restaurants | Displays restaurant details and options |
| Flights | Displays flight details and options |

## 🔗 Page Navigation

The pages are connected using anchor tags:

```html
<a href="index.html">Home</a>
<a href="hotels.html">Hotels</a>
<a href="restaurants.html">Restaurants</a>
<a href="flights.html">Flights</a>
```

## 🚀 How to Run

1. Clone this repository:

```bash
git clone [https://github.com/your-username/travel-website.git](https://github.com/your-username/travel-website.git)
```

2. Open the project folder.

3. Open `index.html` in your web browser.
